📖 How to Add to OBS

Follow these steps to add the viewer widget as an overlay in OBS:

  1. Make sure the Cxeify server is running (check Server Controls tab)
  2. In OBS, add a new Browser Source
  3. Copy the Viewer URL below and paste it into the URL field
  4. Set dimensions (recommended: Width 500px, Height 150px)
  5. Important: Leave the "Custom CSS" field empty
  6. Enable "Shutdown source when not visible" for better performance
  7. Position and resize the overlay as desired

📋 Viewer URL

1 Create Spotify App

Visit the Spotify Developer Dashboard and create a new application:

  • Go to https://developer.spotify.com/dashboard
  • Log in with your Spotify account
  • Click "Create app"
  • Fill in the form:
    • App name: Cxeify (or any name you like)
    • App description: Personal Spotify Controller
    • Redirect URI: http://127.0.0.1:3000/callback
    • APIs used: Select Web API
  • Agree to the terms and click "Save"
2 Get Your Client ID

After creating your app, you'll need your Client ID:

  • Click on "Settings" in your newly created app
  • Copy the Client ID (visible immediately)
  • Keep this credential safe - you'll need it in the next step

🔒 Note: We use PKCE authentication, so you don't need a Client Secret anymore!

3 Start the Server & Configure

Now let's connect Cxeify to your Spotify account:

  • Go to the Settings tab
  • Click "Start Server"
  • Click "Open Setup" to open the configuration page
  • Enter your Client ID
  • Click "Save and Authenticate"
  • Log in with your Spotify account and authorize the app

🎉 Setup Complete! Your server is now configured. Visit the iCue Widget or OBS Widget tabs to learn how to use the widgets.
